# Taskflow

A simple Next.js + TypeScript todo app with filters, a task counter, and Vitest tests.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- Vitest + React Testing Library

## Scripts

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

## Features

- Add, complete, and delete todos
- All / Active / Completed filters
- Active task counter
- Client-only (no database or backend)
